# Minehub – Minecraft Community Website

## Project Overview
Minehub is a Minecraft-themed website I developed using HTML, CSS and JavaScript. The website was created to provide Minecraft-related content in an organised and interactive layout, featuring images, videos and different sections for visitors to explore.

## Technologies Used
- HTML5 – Structuring webpages and website content.
- CSS3 – Styling, layouts, animations and visual design.
- JavaScript – Interactive functionality and user interactions.

## Features
- Interactive navigation and webpage layouts.
- Video carousel with previous and next buttons.
- Scroll-to-top button with smooth scrolling.
- Image hover effects that change images when users interact with them.
- Loading screen displayed before the main website content.
- Custom styling and animations using CSS.

## What I Learned
Through developing Minehub, I gained practical experience building websites using HTML, CSS and JavaScript. I learned how to manipulate webpage elements using the DOM, handle user events and create interactive features. I also improved my understanding of website layouts, styling, animations and user experience.

## Running the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser to view the website.
